# Triage labels

应用分流标签时，使用对应的 GitHub 标签字符串。

| 分流角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交由代理实现 |
| `ready-for-human` | `ready-for-human` | 需要由人实现 |
| `wontfix` | `wontfix` | 决定不处理 |
